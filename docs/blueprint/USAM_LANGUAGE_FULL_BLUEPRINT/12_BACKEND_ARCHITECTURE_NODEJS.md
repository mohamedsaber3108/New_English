# Backend Architecture Nodejs

Express composes learning, customer, operations, leads, static delivery and WebSockets. Security includes scrypt passwords, hashed random sessions/tokens, expiry/single use, HttpOnly SameSite cookies, Secure in production, same-origin mutation checks, server prices, HMAC payment callbacks, payload caps, rate limits and security headers.

## Acceptance and status
**Implemented** means present in source and covered by build or smoke evidence. **Configured** means code exists but needs a deployment secret/provider account. **Planned** means no production claim. English is the only active paid language pack; placement is guidance rather than an accredited CEFR certificate.
