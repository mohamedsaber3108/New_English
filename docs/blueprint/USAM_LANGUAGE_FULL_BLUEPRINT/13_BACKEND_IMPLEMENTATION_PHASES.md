# Backend Implementation Phases

Backend phases B1 learning APIs/rooms, B2 accounts/profile/orders/entitlements, and B3 recovery/email/preferences/support/receipts/admin/audit/events are implemented. Provider configuration and staging validation are next. Scale adds PostgreSQL migrations, queued jobs, Redis realtime/rate limits, idempotency records and named RBAC identities.

## Acceptance and status
**Implemented** means present in source and covered by build or smoke evidence. **Configured** means code exists but needs a deployment secret/provider account. **Planned** means no production claim. English is the only active paid language pack; placement is guidance rather than an accredited CEFR certificate.
