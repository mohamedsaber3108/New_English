# Api Specifications And Integration Contracts

API groups: health/assessment; register/login/logout/me/profile/delete; verification/reset/preferences/sessions; catalog/orders/access/receipts; Paymob webhook; leads; support; feedback/recommendation/simulation/report/coach; events; admin overview/users/orders/support/leads/audit; and WebSocket rooms. Contracts specify JSON, auth, validation and explicit error codes in source.

## Acceptance and status
**Implemented** means present in source and covered by build or smoke evidence. **Configured** means code exists but needs a deployment secret/provider account. **Planned** means no production claim. English is the only active paid language pack; placement is guidance rather than an accredited CEFR certificate.
