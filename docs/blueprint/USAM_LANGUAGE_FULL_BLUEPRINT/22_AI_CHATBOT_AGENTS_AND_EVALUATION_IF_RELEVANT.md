# Ai Chatbot Agents And Evaluation If Relevant

AI supports live scenario continuation and the Plus coach. Inputs and history are limited; prompts constrain role, length, corrections and claims; failure uses guided fallback or a clear unavailable state. Prelaunch evaluation covers level fit, goal fit, useful corrections, unsafe domains, Arabic explanations, false scoring claims, injection, latency and cost.

## Acceptance and status
**Implemented** means present in source and covered by build or smoke evidence. **Configured** means code exists but needs a deployment secret/provider account. **Planned** means no production claim. English is the only active paid language pack; placement is guidance rather than an accredited CEFR certificate.
