# Payments Subscriptions Billing If Relevant

Paymob Intention creates hosted checkout. The server selects EGP amount, stores a USL reference and grants access only after a matching HMAC-verified nonpending success. Redirects never activate access. Matching refund/void removes entitlement; duplicate transaction IDs are ignored. Launch requires sandbox success/failure/refund/duplicate and live low-value reconciliation.

## Acceptance and status
**Implemented** means present in source and covered by build or smoke evidence. **Configured** means code exists but needs a deployment secret/provider account. **Planned** means no production claim. English is the only active paid language pack; placement is guidance rather than an accredited CEFR certificate.
