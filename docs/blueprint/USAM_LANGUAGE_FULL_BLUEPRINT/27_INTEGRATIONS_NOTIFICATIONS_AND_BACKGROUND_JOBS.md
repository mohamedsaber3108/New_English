# Integrations Notifications And Background Jobs

Integrations: Paymob for checkout/webhook, Resend for verification/reset, OpenAI for live dialogue, Web Speech for browser voice, and USAM ecosystem links. Failure behavior is explicit and safe. Add queued retries, webhook reconciliation, expiry reminders, stale-ticket alerts, deletion jobs and daily aggregates with idempotent keys after queue infrastructure.

## Acceptance and status
**Implemented** means present in source and covered by build or smoke evidence. **Configured** means code exists but needs a deployment secret/provider account. **Planned** means no production claim. English is the only active paid language pack; placement is guidance rather than an accredited CEFR certificate.
