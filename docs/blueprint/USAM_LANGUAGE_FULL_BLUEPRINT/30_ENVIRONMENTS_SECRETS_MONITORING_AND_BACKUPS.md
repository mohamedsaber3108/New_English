# Environments Secrets Monitoring And Backups

Environments are local preview, provider-sandbox staging and production. Never copy production customers to lower environments. Secrets stay outside Git with mode 600 and rotation rules. Monitor health, errors, restarts, disk, TLS, checkout/webhook/email/AI failures, open-ticket age and backup success. Run encrypted offsite backups and quarterly restore drills.
